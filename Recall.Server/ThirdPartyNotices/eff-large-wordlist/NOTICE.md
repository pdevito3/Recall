# EFF long word list

The Server carries the words of the EFF long word list, `Auth/Passwords/eff-large-wordlist.txt`, inside `Recall.Server.dll`. A temporary password is made from words of this list.

The file keeps the 7,776 words and drops the dice numbers. `scripts/build-password-lists.cs` builds it.
