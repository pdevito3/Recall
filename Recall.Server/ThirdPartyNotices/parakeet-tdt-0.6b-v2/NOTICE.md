# Parakeet TDT 0.6B V2

The image does not carry this model. Recall downloads it on first use into `/data/models`.

Model: NVIDIA Parakeet TDT 0.6B V2, converted to ONNX by the sherpa-onnx project.

Source: https://huggingface.co/csukuangfj/sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8

Original: https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2

The conversion changes the format of the model and quantizes its weights to 8 bits.
